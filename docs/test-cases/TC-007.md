# TC-007: My Account opens with an API token cookie
Linked criteria: F-03 AC-01 ([F-03](../features/F-03-my-account.md))
Type: functional
Priority: P1
Tags: smoke
Automation: Not started
## Preconditions
- The store is running.
- Admin credentials available.
## Steps
1. `POST /api/login` to get a token.
2. Open My Account.
3. Set `document.cookie = token=<token>`.
4. Open My Account again.
## Expected result
The My Account page heading is visible.
